# DN-002: Bootstrap repository conventions

Status: Proposed

## Outcome
Make the repository easy to navigate and work on with Cursor.

## Scope
- Add/confirm root instructions, docs layout, `.cursor/rules/`, skills, and task template.
- Add ignore rules only after inspecting current files.
- Do not generate application services yet.

## Acceptance criteria
- [ ] Instructions do not conflict.
- [ ] Cursor recognizes project rules and skills in the current installation.
- [ ] No application feature code is added.
- [ ] Setup instructions are documented.
