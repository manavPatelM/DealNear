# Prompt 06: Release Readiness

Assess whether the current DealNear milestone is ready to release. Inspect the repository, current status, tests, configuration, deployment manifests, and documentation.

Report:
- Acceptance criteria met/not met.
- Commands actually run and results.
- Known defects and security findings.
- Migration, rollback, backup, and recovery considerations.
- Observability and alerting gaps.
- Estimated cloud-cost risks or resources that may remain billable.
- A go/no-go recommendation with reasons.

Do not deploy, apply Terraform, destroy resources, or change production settings.
